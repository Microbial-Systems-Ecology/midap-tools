# NEWS

## v1.3.0.9000 (dev)

- Implemented `calculate_lag_time(boundary_time, frame_column, id_column, lineage_column, lag_time_column, agg, allow_negative)`: adds a `lag_time` column to every track — the difference between its actual cycle duration and the per-lineage reference derived from baseline tracks (those ending before `boundary_time`). All tracks receive a value; baseline tracks scatter around 0 (exactly zero in aggregate with `agg="mean"`). Tracks whose lineage has no baseline data receive NaN. Underlying pure function `compute_lag_time` lives in `analysis/life_cycle.py`.
- Implemented `calculate_grouped_rank(group_columns, value_column, rank_column, ascending)`: ranks rows within each group (e.g. by x-position within each frame/chamber) and broadcasts integer ranks as a new column.
- Implemented `calculate_grouped_metric(group_columns, value_column, mode, metric_column)`: computes a group-level summary (min/max/mean/median/sd) and broadcasts it as a new column. Both methods are also available as standalone analysis functions (`grouped_rank`, `grouped_metric` in `analysis/grouped_analyses.py`) callable via `calculate_dataframe_operation`.
- Implemented `calculate_time_to_split(frame_column, id_column, life_cycle_column, time_to_split_column)`: adds two columns derived from per-track durations. `life_cycle` = total track span (max − min of `frame_column` per track). `time_to_split` = remaining time per row (track max − current row value). Both work with integer and float frame columns (e.g. raw "frame" or "time_hour"). Underlying pure functions `compute_life_cycle` / `compute_time_to_split` live in `analysis/life_cycle.py`.
- Implemented `plot_time_to_split(time_to_split_column, frame_column, group_by, flip_grouping, start_times, n_bins, plot_types)`: plots time-to-split distributions evaluated at user-defined or auto-generated snapshot times. Supports three chart types via `plot_types`: `"boxplot"` (duration distributions with strip overlay), `"survival"` (per-start-time survival curves in a faceted figure), and `"heatmap"` (2-D survival heatmap — rows = start times, columns = duration, color = fraction not split). Underlying plotting functions live in `plotting/time_to_split_plots.py`.
- Implemented `align_frames(frame_column, out_column)`: aligns all positions to their shared frame range (intersection across positions) and writes reindexed values to `out_column` (default: `"frame_aligned"`). In new-column mode all rows are kept; rows outside the shared range receive `NaN`. Set `out_column="frame"` to overwrite in place (drops rows, shifts `first_frame`/`last_frame`).
- Implemented `apply_offset_correction(offsets, by_group, frame_column, out_column)`: shifts frame values forward for selected positions, writing results to `out_column` (default: `"frame_offset"`). In new-column mode the original `frame` column is preserved for bitmap/HDF5 indexing. Set `out_column="frame"` to overwrite in place. Accepts a dict of `position → offset` (direct mode) or `group_value → offset` (by_group mode via metadata).
- Implemented `create_new_lineage(start_frame, output_column, orphans_as_root)`: rebuilds cell lineage from a given frame index. Cells present at `start_frame` become lineage roots; all descendants inherit the root's `trackID` as `lineageID_postfix`. Rows before `start_frame` receive `NA`. Orphan trackIDs (appearing after `start_frame` with no traceable ancestor) are self-rooted by default.
